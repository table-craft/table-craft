How it works

You describe the game. Tablecraft runs it, renders it and keeps everyone honest.

1

Write the rules

A game is a plain module: setup() deals, moves validate and change state, endIf() decides the winner. State is JSON; randomness is seeded and replayable.

moves: {
  roll(s, ctx) {
    if (cur(s).id !== ctx.playerId) return { error: 'Not your turn' };
    const r = ctx.roll(6, { id: 'die', by: ctx.playerId });
    s.pos[ctx.playerId] += r.face;
    return s;
  },
}
2

Describe the table

view() returns what this player may see: zones, cards, dice, tokens, a HUD. Opponents' cards simply have no face. Same ids move between zones — and animate.

view(s, { playerId }) {
  return { type: 'tabletop', scene: {
    zones: [{ id: 'market', layout: 'row', label: 'Market' }],
    objects: s.market.map((id) => ({
      id, kind: 'card', zone: 'market', enterFrom: 'deck',
      face: { title: CARDS[id].name, text: CARDS[id].text },
      click: { name: 'buy', args: { id } },
    })),
  }, hud: { log: s.log } };
}
3

Play anywhere

Run it in the browser against bots, or put it on a room server for real multiplayer. The client is identical; only the source of truth moves.

// local, no server
const match = createLocalMatch({ source, players: ['You', 'bot', 'bot'] });
// or online
const match = connectRoom({ io, url, room: 'AB12CD', name: 'Ada' });

<TablecraftGame client={match} />
Built for watching, not just playing

Nobody loses track of the game.

Bots move fast and opponents play cards on the far side of the table. Tablecraft detects every card that is revealed, played, given or discarded and puts it on stage — large, readable, with who did it and the line from your game log.

  • Spotlight — one move at a time, pausable, never piling up.
  • Game log — rounds, coloured player names, card thumbnails, dice results.
  • Readable pace — bots wait longer after dice, banners and reveals.
  • Turn cues — "Your turn" with sound, camera and a glowing decision dock.

Everything a tabletop needs

⚖️

Server-authoritative

Clients send intents; the rules run in a sandbox with per-call timeouts. No cheating by editing the page.

🎲

Physics that agrees

Dice are thrown with cannon-es and land on the face the server rolled. Tokens toss and stack; cards arc, tilt and flip.

🙈

Hidden information

view() is per player. Hands, decks and secret roles never reach the wrong browser.

🤖

Bots & referee

Export actions() and you get bots for free — plus a referee that plays hundreds of games and reports rule bugs.

🃏

Cards from data

Title, text, chips, corner badges and art. No art yet? A clean illustration is drawn for you until it exists.

🌍

Rooms you host

createRoomServer() on socket.io: lobby, seats, bots, sand timers, pacing. Your server, your data.

🎧

Sound & atmosphere

Procedural card, dice and coin sounds with room reverb, ambience and six lighting presets.

⚛️

React or not

<TablecraftGame>, <Tabletop> or mountGame(el) for any page. Themeable with CSS variables; English and Turkish built in.

✨

AI-ready

npx tablecraft mcp lets Claude write a game, run the referee, audit every player's view and step through matches with you.

Drop it into your app

import { createLocalMatch } from 'tablecraft';
import { TablecraftGame } from 'tablecraft/react';
import 'tablecraft/style.css';
import source from './treasure-road.js?raw';

const match = createLocalMatch({ source, players: ['You', 'bot', 'bot'] });

export default function App() {
  return <TablecraftGame client={match} style={{ height: '100vh' }} />;
}
import { mountGame, createLocalMatch } from 'tablecraft/embed';
import 'tablecraft/style.css';

const source = await (await fetch('/games/treasure-road.js')).text();
mountGame(document.getElementById('table'), {
  client: createLocalMatch({ source, players: ['You', 'bot'] }),
  locale: 'en',
});
import fs from 'node:fs';
import { createServer } from 'node:http';
import { Server } from 'socket.io';
import { createRoomServer } from 'tablecraft/server';

const http = createServer();
const rooms = createRoomServer(new Server(http).of('/tablecraft'));
const code = rooms.createRoom({ source: fs.readFileSync('game.js', 'utf8') });

http.listen(3000, () => console.log('room', code));
// client: connectRoom({ io, url: 'http://localhost:3000', room: code, name })
import { simulate, summarize } from 'tablecraft/server';

const report = simulate(source, { games: 200 });
console.log(summarize(report));
// 200 games · 200 finished · 0 stuck · 0 hit the move cap · avg 18 moves
// …or every move actions() offered but move() rejected, stuck states,
//   invariant violations and broken scenes — with the game, move and args.
