# Code of conduct

Tablecraft is a project for people who make and play games. We want the issue tracker, discussions and pull requests
to feel like a good game night: welcoming to newcomers, honest about rules, generous with explanations.

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind and assume good intent. Critique ideas and code, never people.
- Welcome questions from beginners — many contributors here are designers first and programmers second.
- No harassment, discrimination, sexualised language or imagery, trolling, or publishing others' private information.
- Respect "no" and moderators' decisions.

## Scope

This code applies in all project spaces — issues, pull requests, discussions, the docs site — and when someone
represents the project in public.

## Reporting

Report unacceptable behaviour privately to the maintainers through
[GitHub's private reporting](https://github.com/table-craft/table-craft/security/advisories/new) or by contacting a
maintainer listed in the repository. All reports are reviewed promptly and kept confidential. Maintainers follow the
Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, permanent ban.
